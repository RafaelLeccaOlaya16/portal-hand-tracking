# portal-hand-tracking
Detección de manos en tiempo real con Python, OpenCV y MediaPipe, con filtros visuales.

## Tecnologías
Python, OpenCV, MediaPipe, NumPy

## Filtros
Boceto, pixelado, invertido y térmico.

## Cómo ejecutarlo
pip install -r requirements.txt
python Portal.py

La primera vez se descarga automáticamente el modelo de MediaPipe.
